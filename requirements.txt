# LLM Tool - dependency entry point
#
# The real dependency list lives in pyproject.toml. This file exists so that the
# habitual `pip install -r requirements.txt` does the right thing, and so that
# tooling which looks for a requirements file finds one.
#
#   pip install -r requirements.txt          core pipeline
#   pip install -e ".[all]"                  recommended: core + every optional feature
#   pip install -e ".[dev]"                  core + test and lint tooling
#
# It used to hold a `pip freeze` taken on macOS. That pinned ~200 exact versions
# -- including packages this project never imports, an editable git checkout of
# the project itself, and a `pyarrow<19` cap that silently held `datasets` back
# at 4.0.0 -- and none of it was reproducible on Windows or Linux. Ranges in
# pyproject.toml resolve correctly on all three.
#
# For a byte-identical environment, generate a lock file per platform:
#   pip freeze --exclude-editable > requirements-lock-windows.txt

--editable .
